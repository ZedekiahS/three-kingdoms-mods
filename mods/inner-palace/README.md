# 后宫机制 Mod（开发暂停快照）

截至 **2026-11-08**。这是可继续开发的源码和调查记录，**不是已完成的发布版**。用户要求暂时停止实机调试，先提交仓库；本次上传不更换游戏中的包。

## 已有功能

- 入口放在原版「派系 → 人物」之后，复用府署人物卡、效果提示和分阶段任职操作。
- 14 个固定名位：皇后 1、贵人 2、美人 3、宫人 3、采女 5；皇后与君主同排。未称帝与称帝的背景跟随原版规则。
- 面向原版汉文化派系的新开局，已扩展到 10 份开局文件；刘表不再是唯一目标。各派系/剧本未全部实机验收。
- 皇后、贵人可启用任职角色的派系范围增益，其余三类不启用；已有吕布、袁术的局部验证和用户效果反馈。
- 保留成年女性、婚姻及家族限制；君主现任成年女性配偶是已婚例外。女儿可出现在名单，但不能任职。
- 原配在条件满足且皇后空缺时自动入位；用户已确认严夫人、冯夫人显示。不会在每次刷新时强制撤销玩家安排。

## 当前未完成

配偶名单漏人的原因已定位并修复表达式，隔离测试中冯夫人已显示。最新的「休妻（移出后宫）」动作尚未通过完整实机验收：以前的按钮改造版本有载入崩溃，最新最小改造方案仅完成构建和结构检查。**不能把按钮文字或 payload 数据存在当作婚姻已经解除。**

需求规则：改封到贵人/美人应保留婚姻；配偶主动移出后宫应同时离婚、撤位。当前多名位任职系统并未实现所有妃嫔与君主的真实多人婚姻。
